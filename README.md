# Information-security-framework

## LankaEdu university 

A practical information security framework developed for a fictional university environment 

The project focuses on protecting organizational information and systems using fundamental information security principles, including the CIA triad 

- Confidentiality 
- Integrity
- Availability

## Project objectives 

- Identify important organizational assets.
- Identify potential threats and vulnarabilities.
- Assess information security risks.
- Evaluate confidentiality, integrity and availability impacts.
- Recommending appropriate security controls.
- Develop incident response and disaster recovery plans.
- Develop security policies and procedures.
