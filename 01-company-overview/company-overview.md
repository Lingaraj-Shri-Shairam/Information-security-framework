# LankaEdu University — Company Overview

## 1. Organization Overview

LankaEdu University is a fictional medium-sized private university located in Sri Lanka. The university provides undergraduate and postgraduate education and relies heavily on information technology to support academic, administrative, financial, and student-related activities.This organization is created as a fictional case study for the development of an Information Security Framework.

## 4. Major Information Systems

The university uses several information systems to support its operations:

### Student Management System

The Student Management System stores and manages student information, academic records, course information, grades, and attendance information.

### Student Portal

The Student Portal allows students to register for courses, view grades, access schedules, download documents, and submit requests.

### University Email System

The university email system is used by students, lecturers, administrative staff, management, and IT personnel for communication.

### Learning Management System

The Learning Management System provides lecture materials, assignments, assessments, and other academic resources.

### Financial Management System

The Financial Management System stores and processes financial information including student payments, university financial records, supplier information, and payroll information.

### Human Resources System

The Human Resources System stores employee information, employment records, salary information, and leave records.

### File Server

The internal file server stores university documents, policies, reports, academic documents, and administrative information.

### University Website

The public university website provides information about courses, admissions, university services, news, and contact details.

## 7. Information Security Importance

Protecting the university's information and systems is essential because a security incident could affect students, employees, university operations, finances, and reputation.

The security framework will therefore focus on the three fundamental objectives of information security:

  Confidentiality — Preventing unauthorized access to information.
  Integrity — Preventing unauthorized or improper modification of information.
  Availability — Ensuring information and systems are available when required.

## 8. Purpose of the Security Framework

The purpose of this project is to identify information security risks within the fictional LankaEdu University environment and develop appropriate security controls, policies, risk treatments, incident response procedures, and recovery strategies.

The framework will be developed progressively based on the organization's assets, threats, vulnerabilities, and business requirements.
